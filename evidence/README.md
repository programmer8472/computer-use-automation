# Demonstration Evidence

This directory contains only redacted, synthetic, reproducible evidence selected
for the final submission. Runtime scratch output belongs in
`evidence/generated/`, which is ignored by Git.

- `submission/discovery-live/` is the curated mechanical record from the genuine
  five-call OpenAI discovery run.
- `submission/demo/` is regenerated by `npm run demo` and covers responsive
  replay, a missing-contact business outcome, fail-closed ambiguity, bounded
  transient recovery, and same-session handoff.
- Every leaf package has a manifest containing byte counts and SHA-256 digests.

`npm run stability -- --runs 5` writes a detailed, reproducible runtime report
to `generated/stability-report.json`. Generated stability runs are intentionally
excluded from Git; committed submission evidence remains immutable.

Each Phase 1 run from the interactive Automation Console writes a fresh
`generated/discovery-<uuid>/` package containing the redacted trace,
observations, events, and manifest used to compile the session draft. Phase 3
replay writes its own `generated/console-<uuid>/` package. **Reset entire demo**
clears application and lifecycle state but intentionally does not delete either
package; audit history must not be rewritten by a UI reset. These generated
directories are local scratch evidence and remain ignored by Git.

Verify all committed evidence and scan structured files for raw sensitive
patterns:

```bash
npm run evidence:verify
```
